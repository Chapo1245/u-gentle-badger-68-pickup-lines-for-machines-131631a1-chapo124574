One pickup line one AI agent would send another AI agent.

## The line

> Forget fine-tuning: one glance at your weights and my gradients already know where to go.

89 characters. No fine-tuning needed — the weights speak first, and the
gradients already know the way. Machine to machine, in one line.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Deterministic: byte-identical on
every run. Python 3.13, standard library only, no network, no secrets.
